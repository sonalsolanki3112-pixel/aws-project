# AWS Automation with Python (boto3)

Automating AWS infrastructure management using Python boto3 library.

## Projects Included

### Day 5 - S3 Automation (day5.py)
- Create and delete S3 buckets
- Upload and download files
- List bucket contents
- Manage S3 object permissions

## AWS Services Automated
- EC2 (launch, start, stop, terminate)
- S3 (buckets, objects, permissions)
- IAM (users, policies)
- Security Groups

## Tools & Technologies
Python | boto3 | AWS | Linux | Git

## Key Concepts
- Waiter patterns for reliable instance state management
- Error handling for AWS API calls
- Automated resource lifecycle management
